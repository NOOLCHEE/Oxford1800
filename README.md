# 📝 1800 단어 마스터: 스마트 영단어장 & 퀴즈 보드 (Voca-Quiz Board)
> 별도의 백엔드 API 서버 없이, 브라우저가 1,800개의 단어 데이터를 직접 로드하여 퀴즈(객관식/주관식)와 암기를 완벽하게 지원하는 순수 프론트엔드 단어장 웹 앱입니다.

---

## 📌 주요 기능 (Features)
* **🔌 Zero-API 순수 웹 아키텍처**: 데이터베이스나 백엔드 서버 없이 브라우저의 연산만으로 모든 기능이 완벽히 작동합니다.
* **🎯 2가지 커스텀 퀴즈 모드**: 
  * **객관식 모드**: 1800 단어 풀에서 랜덤하게 뽑힌 오답 보기 4개 중 올바른 뜻을 고르는 모드.
  * **주관식 모드**: 뜻을 보고 영단어 스펠링을 직접 키보드로 입력해 정답을 맞히는 철자 검토 모드.
* **📊 전체 단어장 목록 조회**: 1,800개의 단어를 카테고리별 혹은 알파벳순으로 정렬하여 간편하게 훑어볼 수 있는 열람 기능.

## 🛠️ 기술 스택 (Tech Stack)
* **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
* **Data Format**: 엑셀 전처리 기반의 초경량 `words.json` 파일 또는 클라이언트 사이드 파싱

## ⚙️ 실행 방법 (How to Run)

이 프로젝트는 서버 설치가 전혀 필요 없는 구조입니다.

### 1. 로컬 환경에서 바로 보기
1. 프로젝트 파일을 다운로드하거나 복사합니다.
2. 폴더 내의 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 열면 **즉시 실행**됩니다.

### 2. 데이터 연동 구조
* 1800 단어 엑셀 파일은 브라우저에서 빠르게 읽을 수 있도록 `data/words.json` 포맷으로 최적화되어 제공되거나 페이지 내부에 포함됩니다.

## 📂 폴더 구조 (Folder Structure)
```text
├── data/
│   └── oxford_1800.csv       # 단어 데이터 파일
├── js/
│   └── app.js                # [최종] 로드 및 퀴즈 엔진 자바스크립트 파일
├── index.html                # [최종] 화면 마크업 및 스타일 파일
└── README.md
```

## 🚀 배포 방법 (Deployment)
정적 파일들만 존재하므로 **Cloudflare Pages**, GitHub Pages, Vercel, 혹은 Netlify 같은 정적 웹 호스팅 서비스에 폴더 통째로 드래그 앤 드롭하여 10초 만에 무료 배포가 가능합니다.
